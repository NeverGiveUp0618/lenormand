# 雷诺曼 · 三十六牌

移动端优先的雷诺曼学习站：**学（5 课）· 查（36 牌 + 组合器）· 练（4 种题型 + 4 种牌阵）· 记（抽牌日记）**。

## 文件
| 文件 | 作用 |
|---|---|
| `data.js` | **唯一内容源**：36 张牌（概括/作用/名词形容词动词副词/人物/时间/关键词）、4 种牌阵、5 课讲解 |
| `icons.js` | 36 张牌的自绘 SVG 线描图标 |
| `app.js` | 路由 + 四个视图 + 出题引擎 + localStorage |
| `index.html` | 页面骨架与全部样式 |
| `content/` | 公众号五课的提取原文（图文原序）。**个人对照用，`.gitignore` 已排除，不发布** |

## 改内容
只改 `data.js`，改完跑 `node tests/test.js`，再把 `sw.js` 里的 `V` 版本号 +1。

## 组合语法
第一张牌 = 名词（主语），第二张 = 形容词/动词（修饰）。顺序反过来意思就变，这是全站出题和组合器的依据。
